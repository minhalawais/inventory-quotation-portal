15. CREATE OR RESET A USER PASSWORD
============================================================

Use this carefully. Replace email and password:

sudo -u deploy bash -lc 'cd /var/www/inventory-quotation-portal && node -e "require(\"dotenv\").config({path:\".env.local\"}); const {MongoClient}=require(\"mongodb\"); const bcrypt=require(\"bcryptjs\"); (async()=>{const client=new MongoClient(process.env.MONGODB_URI); await client.connect(); const db=client.db(\"inventory_portal\"); const hash=await bcrypt.hash(\"NEW_PASSWORD_HERE\",12); const result=await db.collection(\"users\").updateOne({email:\"USER_EMAIL_HERE\"}, {$set:{password:hash, updatedAt:new Date()}}); console.log(result); await client.close();})().catch((e)=>{console.error(e); process.exit(1)})"'

27. COMMON PROBLEMS
============================================================

Problem:
Site redirects to localhost.

Fix:
Check .env.local:

sudo -u deploy bash -lc 'cd /var/www/inventory-quotation-portal && grep NEXTAUTH_URL .env.local'

Set:

NEXTAUTH_URL=http://187.53.139.52

Then:

sudo -u deploy pm2 restart inventory-quotation-portal --update-env


Problem:
502 Bad Gateway.

Fix:

sudo -u deploy pm2 status

sudo -u deploy pm2 logs inventory-quotation-portal --lines 100

curl -I http://127.0.0.1:3000/auth/signin

systemctl status nginx


Problem:
npm ci fails with ENOTEMPTY.

Fix:

sudo -u deploy bash -lc 'cd /var/www/inventory-quotation-portal && rm -rf node_modules && npm ci'


Problem:
Login fails after domain change.

Fix:
Make sure NEXTAUTH_URL exactly matches the public URL:

NEXTAUTH_URL=https://yourdomain.com

Then:

sudo -u deploy pm2 restart inventory-quotation-portal --update-env


Problem:
Username login does not work for old users.

Fix:

sudo -u deploy bash -lc 'cd /var/www/inventory-quotation-portal && npm run db:migrate'

Then inspect:

mongosh inventory_portal --quiet --eval 'db.users.find({}, {email:1, username:1}).forEach(printjson)'
